# 📊 Social Media Engagement Analysis | Python

## 📌 Project Overview
An exploratory data analysis project using Python to understand social media engagement, content performance, and audience behavior across different post types, categories, and countries.

## 🛠️ Tech Stack
- **Python** — Data analysis
- **Pandas & NumPy** — Data manipulation and numerical operations
- **Matplotlib & Seaborn** — Data visualization

## 🔍 Key Activities
- Imported and explored a dataset containing **5,000 records and 19 columns**.
- Cleaned missing values and standardized data formats.
- Converted date columns and corrected data types.
- Checked duplicate records and reviewed engagement metrics.
- Analyzed likes, comments, shares, impressions, watch time, and engagement rate.
- Explored audience demographics, post categories, devices, and sentiment.

## 📈 Key Findings
- The dataset contains **5,000 records** covering social media posts and audience engagement.
- **9,993 hashtags** were recorded across the dataset.
- No duplicate rows were identified during the initial duplicate check.
- Missing values were handled using median, mean, and forward-fill methods, depending on the column.

## 🎯 Learning Outcomes
Strengthened practical skills in Python, data cleaning, exploratory data analysis (EDA), descriptive statistics, and data preparation.

## 📁 Project Files
- `module 5 end assign python.ipynb` — Jupyter Notebook containing the analysis.
- `social_media_engagement_5000.csv` — Dataset used for analysis.

A hands-on learning assignment focused on developing foundational data analytics skills and turning raw data into meaningful insights.
